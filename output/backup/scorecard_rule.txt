Verdict rule (vs. the original study): if the original effect is statistically significant (p < 0.05), a check gets 'Holds' when its estimate has the same sign and p < 0.05; 'Weaker' when it has the same sign but p >= 0.05; 'Disappears or reverses' when its sign flips. If the original found no clear effect (p >= 0.05), the check gets 'No clear effect' unless it is significant, in which case it is flagged.
